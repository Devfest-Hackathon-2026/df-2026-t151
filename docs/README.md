## 作業を始めるとき

1. [AGENTS.md](../AGENTS.md)と[PROJECT_MEMORY.md](PROJECT_MEMORY.md)を確認する。
2. [要件定義書](よりみち要件定義書.md)・[開発分担表](開発分担表.md)・[API仕様](API入出力仕様.md)で担当範囲と完成条件を確認する。
3. [開発環境](開発環境.md)で起動し、[GitHub運用ルール](GitHub運用ルール.md)に沿って作業ブランチを作る。

[自動テスト用の架空データ](../fixtures/search-success.json)はfixturesフォルダに置きます。アプリの架空デモは削除済みで、画面・実APIはfixturesを読み込みません。実際の検索結果や施設情報ではありません。

資料内のコマンドとsrc/・fixtures/などの作業パスは、特記がなければリポジトリルートを基準にしています。日時の付いた記録や改訂履歴は当時の状態を示すため、現在の状態はルートのREADMEと各資料の最新の追記を併せて確認してください。
